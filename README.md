# DutyShield

AI agent that finds the money small importers are owed.

Small importers overpay customs duties on past shipments and on every
shipment going forward, and most have no customs expert to catch it.
This project reads their import records and invoices, flags tariff refunds
and ongoing duty savings, and prepares a filing-ready claim package for
a licensed broker to submit.

**Business model:** Free 10-shipment scan, then $3,500/month pre-clearance protection + $2,500 audit filing fee + 10% of recovered refunds.

**Stack:** Cloudflare Workers, Workers AI, D1, R2.

**Built at:** CaseHacks Hackday, Wilfrid Laurier University (November 2026)
